## 1. 任务与受众

**谁**：跨部门办事的同事（非技术），把一组案卷文件夹（每户/每案一个文件夹）批量合成 A4 PDF，然后打印归档。桌面工具，Windows，无网络。

**三种时刻都要顾及**（用户明确要求）：

| 时刻 | 他脑子里的问题 | 界面必须回答 |
|---|---|---|
| 首次使用 | 我该先点什么？ | 空状态直接给出三步路径 |
| 熟练批量 | 能不能快一点、少点两次？ | 默认值合理、高级项不挡路、勾选批量操作顺手 |
| 报障回来 | 哪一册错了、为什么？ | 目标行状态可见、日志可读、完成后可定位 |

**任务**：① 选根目录 → ② 勾选要合并的文件夹 → ③ 点「开始合并」→ ④ 看结果。

## 2. 结果与证据

**主任务**：一次不求助地把「选目录 → 勾目标 → 开始」走完，并知道会发生什么。

**成功**：首次使用者不查说明、不问人，能独立完成一次合并。

**证据（界面必须自己说出来的事实）**：

- 目标列表状态行：「已选 3/8 个文件夹 · 将生成 3 册」——选之前就知道结果规模；
- 主按钮旁一句话：「将把 3 个文件夹各自合成一册 A4 PDF」——点之前知道会发生什么；
- 运行中：当前文件夹 + 当前文件 + `n/m` 进度 + 可取消；
- 完成后：状态栏「成功 3/3，共 21 页」+ 结果对话框（本次不改其视觉）。

**本项目独有、通用模板给不了的**：每一册的**页数、体积、输出路径**在合并前后都摆在同一处，供打印前核对；失败永远带「原因 + 跳过页数」，不是一句"失败"。

## 3. 选定方向

- **视觉权威**：DESIGN.md（纸白 `#ffffff`、衬底 `#f7f8fa`、发丝线 `#d9dde3`、主墨 `#333333`、次墨 `#555555`、唯一强调色任务蓝 `#1565c0`、绿/琥珀/红仅表状态；圆角 4/6，8px 网格，无阴影、无渐变、无动效）。
- **结构论点**：**三级信息分层**——顶部「做什么」（标题 + 状态带）、中部「必须填的」（基本设置 + 目标列表 + 主按钮）、底部「可能用到的」（可折叠高级选项）；右侧常驻日志/进度。熟练用户只碰中部，新用户被顶部与空状态引导，排错用户看右侧与结果行。
- **顺序/焦点**：焦点时刻 = **主按钮区**（一个主按钮 + 一句预期结果 + 取消/试运行次要动作），整屏只有这一个实心按钮。
- **实现后果**：新增 `app/theme.py`（token 常量）+ `app/theme.qss`（样式），主窗口控件层级按上述分层重排；逻辑、信号、配置字段零改动。

## 4. 范围与边界

**做**：主窗口（`app/ui_main.py`）的皮肤 + 信息架构重排；空状态引导；高级选项折叠；主按钮区结果预期句；内联校验（复用现有模板校验机制，扩展文案）。

**不做**：结果对话框视觉（另一件事）、core 包逻辑、`legacy/merge_to_a4_wps.py`（永不可改）、CLI、打包流程、版本号/发布。

**明确反目标**：

- 不做第二强调色、不做彩色渐变/阴影/"卡片阴影堆叠"；
- 不加新功能（不加新转换器、不加新选项语义）；
- 不把日志塞进弹窗、不用模态框做首次引导；
- 不移动或删除既有能力（模式 A/B、级别 0/1/2、加密、引擎、诊断、单实例、长路径提示）。

## 5. 状态与范围

**必须设计的状态**：

1. 首次/空状态：未选根目录 → 目标列表区显示三步引导（① 选根目录 ② 勾选文件夹 ③ 点开始）；
2. 已选目录：目标列表填充，状态行「已选 n/m · 将生成 n 册」，主按钮可用；
3. 未勾任何目标：主按钮禁用 + 行内提示「请至少勾选一个文件夹」；
4. 校验错误：模板非法等 → 行内红字 + 按钮禁用（不弹窗）；
5. 运行中：进度、当前文件、取消可用、表单禁用；
6. 完成/失败：状态栏着色 + 结果对话框（既有）；
7. 溢出：目标几十~上百（滚动）、路径超长（省略 + tooltip 全路径）；
8. 长路径未启用/未装 WPS：状态栏既有提示保留。

**数据范围**：目标 1~数十；每目标文件 1~数百；单册 1~几百页；路径最长可超 260 字符。

## 6. 交互与布局（意图，不是 CSS）

- 窗口 1080×720 起，最小 900×600；左右分栏保持约 2:3（左设置、右日志/进度）。
- 顶部：标题「A4 合并助手」+ 一句话用途（「把一组文件夹各自合成一册 A4 PDF」）+ 右侧状态带（引擎/长路径/状态/版本，状态栏保留）。
- 左栏自上而下：**基本设置**（根目录、处理级别、模式 A/B 与输出目录、模板、报告开关）→ **目标文件夹**（列表 + 全选/全不选 + 状态行）→ **主按钮区**（开始合并〔实心〕、取消、试运行、预期句）→ **高级选项**〔可折叠，默认收起，状态记忆〕。
- 折叠区内容建议：排版（留白、方向、图片适配）、转换（引擎、超时、Excel 跳过、同名成品）、加密（密码、密码文件、不提示、记住）。
- 目标行：勾选 + 相对路径 + 该文件夹素材数；不可合并项（输出目录自身）灰显。
- 焦点顺序：根目录 → 目标列表 → 主按钮；Tab 可全程键盘操作。
- 反馈：一切错误就近显示（行内红字 + 图标），不使用 QMessageBox 做可预期校验。
