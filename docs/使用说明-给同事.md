# A4 合并助手 —— 使用说明（给同事）

> 版本：1.0.2.0（整包更新：用新 exe 覆盖旧 exe 即可，什么都不用装）

## 怎么开始用

1. 把 `A4合并助手.exe` 放到一个**浅目录**（建议 `D:\A4合并助手\`，不要放桌面/同步盘/回收站周边）。
2. **双击** exe 启动（第一次启动要解包自己，等 3~10 秒属正常，别重复双击）。
3. 点「根目录」旁的“浏览…”，选择你要合并的**总目录**（里面每个子文件夹＝一位股东/客户）。
4. 保持默认设置，点「开始合并」。

## 每个选项是干什么的

| 选项 | 默认 | 说明 |
|---|---|---|
| 根目录 | （上次用的） | 总目录；它下面的一级子文件夹＝要处理的目标 |
| 目标文件夹 | 全选 | 只处理勾选中的文件夹 |
| 输出位置 | 各子文件夹内 | 改成“统一输出”后，所有成品集中到一个文件夹 |
| 处理级别 | 1 级子文件夹 | 「当前文件夹」＝把根目录整体合成一份 PDF；「2 级子文件夹」＝再往下一层选择目标文件夹 |
| 文件名模板 | `【合并】{folder}.pdf` | 成品命名；`{folder}`＝文件夹名 |
| 生成 合并报告.txt | 勾选 | 每个任务结束后生成一份说明文档 |
| 四周留白 / A4 方向 / 图片适配 | 0 / 自动 / 铺满 | 排版参数，一般不用动 |
| 转换引擎 | 自动 | 有 WPS 用 WPS；没装 WPS 时图片/文本/PDF 也能合并 |
| 同名成品 | 关 | 勾上后，上次生成的成品也会被重新合并进去（一般不需要） |
| 遇到 Excel 跳过 | 关 | 勾上后 `.xls/.xlsx` 不参与合并、**也不算失败**；结果对话框和报告里单列「跳过的 Excel」清单，取消勾选即恢复原样 |
| 打开密码 | 空 | 遇到加密 PDF 会弹窗问密码；也可以把常用密码每行一个填进去 |
| 遇到加密文件直接跳过 | 关 | 不在一台机器上输入密码时勾上，遇到加密文件就跳过并记录 |
| 仅预览 | 关 | 只算“会合并出什么”，不生成文件 |

## 运行中

- 左下是两个进度条（文件夹、页面），右侧是实时日志，成功/警告/失败会着色。
- 点「取消」数秒内停止；已完成的文件夹保留结果，不会产生半成品。
- 结束会弹出「运行结果」：成功/失败清单，双击任意一行可直接在资源管理器里定位；
  可以一键打开输出目录、打开 `合并报告.txt`、导出 TXT。

## 常见情况

| 情况 | 说明 |
|---|---|
| 报「需要安装 WPS」 | 这台机器没装 WPS。Office（Word/Excel/PPT）必须 WPS 才能转；PDF、图片、txt 不受影响。装 WPS 或把 Office 先另存为 PDF 即可 |
| 加密 PDF | 弹窗输入密码；不记得就“取消”，该文件跳过并进失败清单，不影响其它文件 |
| 坏掉的 PDF | 单个文件失败只进失败清单，其它文件照常合并 |
| 多出一份「合并<根目录名>.pdf」且体积很大 | 一级/二级子文件夹模式下，如果**根目录里直接放着**可合并文件，根目录本身也算一个目标，会把整棵树递归合成一册（与旧脚本行为一致），因此和子文件夹成品内容重复。不想重复就把根层散文件移进子文件夹再跑 |
| 双击没反应 | 第一次启动要解包，等 10 秒；还不行就看看是不是放在受限目录里了（见下） |
| exe 报英文错误 "Could not create temporary directory" | 说明当前环境没有可写的临时目录。换个目录放置 exe（如 `D:\A4合并助手\`）再双击；新版本已内置“临时目录自愈”，多数情况会自动处理 |
| 想换机器用 | 把 exe 拷过去直接用；记住的密码做了本机加密，换机器不生效（要重新输入） |

## 报错时请这样帮我（很重要）

1. 菜单「文件 → 导出诊断包…」→ 保存 zip；
2. 把 **zip + 你刚才的操作路径（点了什么）** 发我。
诊断包里已自动包含：日志、配置（密码已打码）、引擎探测结果、系统信息，维保靠它。
